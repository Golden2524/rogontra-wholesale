# Screenshot checklist

Capture final images only after the original Rogontra interface is complete. Do not use screenshots containing Amazon branding or tutorial assets in the portfolio.

Required captures:

1. Responsive home/catalogue page.
2. Filtered industrial or heavy-equipment listing.
3. Product detail with wholesale and quote information.
4. Cart and delivery estimate.
5. Checkout/payment confirmation in test mode.
6. Customer order history or quote dashboard.
7. API documentation or architecture overview.

Use synthetic, non-sensitive customer details and indicate clearly when a payment or order is in test mode.
